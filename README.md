# Minesweeper in Java

A Minesweeper game  built in Open JDK 26.0.2.1 and IntelliJ IDEA 2026.2.1.

## Features

- Playable board with mines generated upon the first click
- Safe zone on the first click (the first cell always opens up space)
- Automatic revealing of empty cells
- Flagging system using right-click
- Revealed cell counter
- Win and loss conditions
- Reset button
- Sprites

- Java
- Swing
- Object-Oriented Programming
- IntellJ IDEA

## How to Play

- **Left-click:** reveal a cell
- **Right-click:** place or remove a flag
- Avoid mines and reveal all safe cells to win

## How to Run

1. Clone the repository
2. Open the project in IntelliJ (or your favorite IDE)
3. Ensure the "Sprites" folder is in the correct path
4. Run the "GameExecution" class

## Key Takeaways

- Separation of model, logic, and interface
- Use of 2D arrays
- Recursion to reveal empty cells
- Handling left and right clicks
- Building a complete graphical interface in Swing
